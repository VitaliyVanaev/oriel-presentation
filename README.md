# Oriel — презентация

Сайт-презентация приложения Oriel: 3D-модель iPhone с экранами приложения, листается скроллом.

Открыть: https://cxlvcl.github.io/oriel-presentation/

Файлы: `index.html` — страница, `land.js` — карта суши для глобуса из точек, `screens/` — экраны из прототипа.
Чтобы обновить сайт, замените файлы и сделайте push в `main`: GitHub Pages обновится сам через минуту.
